Synchronization

How to create a connector

In Sales Layer go to the Channel’s option in the left menu, then to the Channels marketplace tab, and scroll down until you find the WooCommerce connector's box, as shown in the next image:

Press + create to start configuring the channel.

In the Parameters tab, you will have to Assign new private key, with the option marked in the image.

After that it will appear on screen the Channel private key assigned.

You will need the Connector ID code and this Channel private key to continue with your e-commerce configuration.

To save the channel, click on “Continue and Save“ and “Complete“ in the right corner of the screen.

You have to finish the channel's configuration before configuring it in the WooCommerce plugin.

How to do a first synchronization

Once SL channel is configured and fields mapped, go to Connectors and click the Add connector button to enter your credentials.

You should test synchronization before leaving it automated, to validate the configuration. This should be done in a staging environment.

Before starting, verify to have logs enabled in your WooCommerce store, Sales Layer Woo menu General Parameters.

To start, we suggest starting with a test synchronization with a few items, setting their status as visible (only these items), and adding a tag, that you have to add in the Products tab in Output data as well. This will narrow the scope of items. Remember to include categories and variants for the items selected, to avoid sync errors and make more complete tests.

To test a synchronization it is recommended to use the “Synchronize!“ connector button in the plugin Connectors panel. This is a more controlled and fast manner than setting the auto synchronization.

After the sync has ended, you will be able to verify results downloading the SL logs. These messages will help you to adjust the configuration.

In the logs, if you find an error file, you'll need to correct the issues reported before the next synchronization.

If no errors arise, you can increase the quantity if items gradually until all information is synchronized.

Then, configure the connector in the production site and synchronize.

My connector is stuck

When the connector has started its synchronization and stored the data, a recount of items will be shown in the grid view. While it has pending information to synchronize, the grid information will be reloaded frequently to update this recount:

In case an uncontrolled error has happened and thrown in the cron jobs, this error message will be displayed in your server error log, or displayed in the WooCommerce in the error system, note it so you can be notify SL in order to get help.

Logs

How to download logs
Download them from Tools.
Where are logs stored
They are stored inside the WooCommerce logs folder, in a folder named logs.

Plugin Tools

Download SL Logs
Creates a zip with existing SL logs in the server and download it.
Remove SL Logs
Removes Sales Layer logs from the server.
Delete SL items pending to process
Delete Sales Layer items pending to process stored in a plugin's table. This tool may be useful when identifying problems in the middle of a synchronization.
Delete SL credentials
Delete Sales Layer credentials from existing items, this will affect categories, products and variants.
Clean orphaned multiconn
Removes multiconn records whose site (blog_id) has been deactivated from the connector's multisite targets. This is useful to clean up leftover data after disabling sites in the multisite synchronization settings.
