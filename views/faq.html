Synchronization

How to create a connector
  1. In Sales Layer, go to the Channels option in the left menu, then to the Channels marketplace tab, and scroll down until you find the WooCommerce connector box, as shown in the next image:

  2. Press + Create to start configuring the channel.
  3. In the Parameters tab, assign a new private key with the option marked in the image:

  4. After that, the assigned Channel private key will appear on screen. You will need the Connector ID code and this Channel private key to continue with your e-commerce configuration.
  5. To save the channel, click "Continue and Save" and then "Complete" in the top-right corner of the screen.
  6. You must finish the channel configuration before setting it up in the WooCommerce plugin.
How to do a first synchronization
  1. Once the SL channel is configured and fields are mapped, go to Connectors and click the Add connector button to enter your credentials.
  2. You should test synchronization before leaving it automated to validate the configuration. This should be done in a staging environment.
  3. Before starting, make sure logs are enabled in your WooCommerce store under the Sales Layer menu General Parameters.
  4. We suggest beginning with a test synchronization using a few items: set their status as visible (only these items) and add a tag, which you also need to add in the Products tab under Output data. This will narrow the scope of items. Remember to include categories and variants for the selected items to avoid sync errors and make more complete tests.
  5. To test a synchronization, we recommend using the "Synchronize!" button in the plugin Connectors panel. This is a more controlled and faster approach than setting up auto synchronization.
  6. After the sync has ended, verify the results by downloading the SL logs. These messages will help you adjust the configuration.
  7. In the logs, if you find an error file, you will need to correct the issues reported before the next synchronization.
  8. If no errors arise, you can increase the quantity of items gradually until all information is synchronized.
  9. Then, configure the connector on the production site and synchronize.
My connector is stuck

When the connector has started its synchronization and stored the data, a recount of items will be shown in the grid view. While it has pending information to synchronize, the grid information will be reloaded frequently to update this recount:

If an uncontrolled error occurs during cron execution, the error message will be displayed in your server error log or in the WooCommerce error system. Note it down so you can notify SL in order to get help.

Logs

How to download logs
Download them from Tools.
Where are logs stored
They are stored inside the WooCommerce logs folder, in a folder named logs.

Plugin Tools

Download SL Logs
Creates a zip file with existing SL logs on the server and downloads it.
Remove SL Logs
Removes Sales Layer logs from the server.
Delete SL items pending to process
Deletes Sales Layer items pending processing from the plugin's queue table. This tool may be useful when identifying problems in the middle of a synchronization.
Delete SL credentials
Deletes Sales Layer credentials from existing items. This will affect categories, products and variants.
Clean orphaned multiconn
Removes multiconn records whose site (blog_id) has been deactivated from the connector's multisite targets. This is useful to clean up leftover data after disabling sites in the multisite synchronization settings.
