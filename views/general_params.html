General Parameters

Pagination will only be usable with API Version 1.18.

When reading data from SL API, máximum of items to read on each call. Data will be inserted into database, and then another call will be made until all data is stored.

Sales Layer logs are stored at plugin folder logs.

This will help to have more information about the connector's execution in order to be able to help in case of doubts. If not checked, only the minimum essential data will be sent.
